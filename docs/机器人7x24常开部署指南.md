# 机器人 7×24 常开部署指南（mini 主机方案）

> 目标：让 NapCat + Koishi 机器人全天在线，实时把群里 `.从者行动` / `.御主行动` 写进行动表 Excel，
> 不用再复制聊天内容。本指南面向家用常开的 mini 主机（二手/全新均可，避开云服务器 IP 的 QQ 风控）。

## 一、选购要点（二手咸鱼 / 全新都适用）

**负载极低**：NapCat + Koishi(Node) + Python + openpyxl，空闲内存 <2GB、CPU 几乎为 0。
所以性能不是问题，重点是**稳定、省电、x86**。

| 关注点 | 建议 |
|---|---|
| 架构 | **必须 x86**（Intel/AMD）。别买 ARM 盒子/树莓派——不是跑不了，是 NapCat 兼容性和教程都更折腾 |
| CPU | N100 / N150 / N5095 / J4125 这类 4 核就绰绰有余；再老如 J1900 也能跑但别更低了 |
| 内存 | 4GB 起步，8GB 更舒服（内存条便宜） |
| 硬盘 | 64GB SSD 起步（系统 + 项目 + 数据库足够） |
| 功耗 | 选 10~30W 的（N100 小主机普遍 ~15W，7×24 一个月电费约 10 块） |
| 避坑 | 看准「能装 Windows / 支持 7×24」；问清电源是外置 DC（坏了好换）还是内置 |
| 散热 | 被动散热或低转速风扇即可，别买满载风扇吵的 |

### 全新购买参考（2026 年行情）

- **整机（N100/N150 + 8G + 256G SSD）≈ 600~900 元**：京东自营有 来酷（Lecoo）MINI SE 这类 N100 整机（评价多、售后稳），零刻 EQ12 / 铭凡 / 极摩客 也有对应款。
- **准系统（无内存硬盘）≈ 400~600 元**：自己配 8G 内存 + 256G NVMe（约 +150 元），最省钱。
- **别买超过 1000 的**：那些是双网口软路由/高端款（如铭凡 MS-01、i9 款）的溢价，你这个负载完全用不上。
- 品牌优先：零刻（Beelink）、铭凡（Minisforum）、极摩客（GMKtec）、来酷（Lecoo，联想系）——认准有质保、评价多的店。
- 二手 vs 全新：差价 200~300 元以内建议直接买新（7×24 挂着，全新质保省心）；差价大再考虑咸鱼。

### 用闲置笔记本替代（省钱首选）

**完全不买也能跑**：手头有闲置/旧笔记本（i3/i5、4G+ 内存都行）就直接用它，负载极小。注意：

- **只用插电**：电池长期满电放着容易鼓包——能拆电池就拆了只用电源适配器，不能拆就把电池充电上限设到 60~80%（联想/华硕等品牌控制中心有这选项）。
- **合盖不休眠**：Windows 电源设置里，插电时"合上盖子"选"不采取任何操作"、"睡眠"选"从不"。
- **散热**：垫高或放散热架上，别放床/沙发上堵住出风口。
- **开机自启**：后端和机器人做成计划任务（登录时/开机运行），断电恢复后自动拉起来。
- **远程管理**：Tailscale + 远程桌面（RDP），出门也能连。
- **别用主力机**：如果只有一台日常用的笔记本，7×24 挂着会占用且不方便；优先翻翻有没有退役的旧本子。

## 二、系统选择：Windows（推荐）

- **Windows**：NapCat Windows 版直接跑、Python/Node/Excel 路径都好弄，与当前项目习惯一致，最省心。
- Linux（Ubuntu/Debian）：更省资源、远程管理更顺，但 NapCat 要折腾（Linux 版/容器），新手不建议第一台就上。

## 三、部署步骤（机器到手后）

1. **装系统**（Windows 10/11 LTSC 或 Win10 都行）+ 关闭自动休眠。
2. **装 Python**（勾选 Add to PATH）+ `pip install openpyxl`。
3. **装 Node.js LTS**。
4. **装 NapCat**（Windows 版，选 WS 服务端，端口 3001）+ 用**机器人小号**登录（别用主号，见风险）。
5. **拷贝项目**：把整个 `fate-gm-helper-main`（或至少 `my-koishi-bot` + `backend-node` + `.dsh` + `1.15`）拷到机器上，例如 `D:\fate-gm-helper-main`。
6. **改路径**（三处写死了本地路径）：
   - `my-koishi-bot\koishi.yml` → `xlsxPath` / `actionLogScript` 改为新机器的绝对路径；
   - 后端 `FATE_GM_DB_PATH`（如需要换数据库位置）；
   - 若后端也搬过去，`koishi.yml` 的 `apiBase` 保持 `http://localhost:8100/api` 即可。
7. **安装依赖并启动**：
   ```
   cd backend-node && npm install && node index.js        # 后端 8100
   cd my-koishi-bot && yarn install && yarn start          # 机器人
   ```
   验证：群里发 `.行动表`，应返回当前状态；发 `.从者行动 测试`，Excel 里出现记录。
8. **开机自启**：把上面两个启动命令做成计划任务（开机运行）/ NSSM 服务，保证断电重启后自动恢复。

## 四、数据同步（重要：Excel 在服务器上，GM 怎么看）

机器人写的是服务器上的 Excel，你平时在电脑上看不到 → 需要同步方案，二选一：

- **Syncthing（推荐，免费双向同步）**：服务器和你的电脑各装一个，同步 `1.15` 目录。机器人写 → 自动同步到你电脑；你在电脑上改 → 同步回服务器（注意：**别在电脑上开着 Excel 编辑的同时机器人写**，会冲突）。
- **网盘文件夹（坚果云/OneDrive）**：把 `1.15` 放进同步盘，两边都指向同一同步文件夹。简单但写频繁时有冲突风险，建议开团时暂停机器人写入。

> 小优点：服务器上没人打开 Excel，之前"Excel 被占用写不进"的问题在服务器上天然不存在。

## 五、风险与注意

- **QQ 风控**：机器人小号新设备登录可能要滑块/短信验证；**别频繁换 IP/设备**，别用小号干别的，尽量固定在这个机器上跑。
- **消息只有在线才收得到**：机器人掉线期间的消息收不到（QQ 协议限制）。掉线补录走 AI 会话（action-log skill）。
- **备份**：定期把 `1.15`（Excel + state + 交接/判例）和 `backend-node\data\gm_helper.db` 拷回电脑一份。
- **远程管理**：装 Tailscale（免费）把两台设备组网，出门也能 ssh/远程桌面到 mini 主机。

## 七、常见问题：公网 IP / 内网穿透

**Q1：机器人在家跑，需要公网 IP 或内网穿透吗？**
不需要。NapCat + Koishi 全是**出站连接**（主动连 QQ 服务器），家里 NAT 后面直接跑，和"有没有公网 IP"完全无关。

**Q2：那我想要别人连进家里（比如开我的世界服务器）呢？**
那才需要"入站连接"，三个办法：
1. **找运营商要 IPv4 公网 IP**：电信/联通打客服电话一般能申请（说家里有监控/NAS 要用），移动比较难；公网 IP 通常是动态的，配个 DDNS（如花生壳、阿里云解析）就行。
2. **内网穿透**：国内 MC 玩家最常用 [樱花 frp（SakuraFrp）](https://www.natfrp.com/)（免费档够开小服）或 [playit.gg](https://playit.gg/)（免费，专门为 MC 设计）；不想用第三方就自建 frp——但 frp 服务端需要一台有公网 IP 的机器，那才回到"买服务器"的话题。
3. **IPv6**：现在很多家宽有 IPv6 公网地址，MC 支持 IPv6 直连，但要求你的朋友也在 IPv6 网络。

**Q3：远程管理 mini 主机用啥？**
[Tailscale](https://tailscale.com/)（免费组网，无需公网 IP）或 Syncthing（数据同步，靠中转服务器也能通）。这两样都不需要公网 IP。

**Q4：机器人和 MC 服务器放同一台 N100 行吗？**
机器人负载可忽略；MC 原版小服（三五个人）在 N100 上也能跑，但开模组/人数多就吃力了——人多建议分开，或买强一点的（如 N305 / i5 档）。
