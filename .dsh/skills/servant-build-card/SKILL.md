# 空想圣杯 构筑搓卡（servant-build-card）

帮 AI（或人）按规则搓出**能过账、能上台、死得明白**的构筑卡。
核心原则：**所有效果必须查原文，所有账目必须过脚本，所有含糊处必须标 GM 问题。**

## 一、规则原文在哪（查证用，禁止凭记忆写效果）

| 文件 | 内容 |
|---|---|
| `knowledge/从者资源库.md` | 从者 RP 价格表、职阶技能、保有技能、基础宝具 |
| `knowledge/从者扩充包.md` | 扩充技能宝具（狮子环、空中庭园、支援咒术在这里） |
| `knowledge/特供资源.md` | 特供卡（牛王反转、无限剑制等） |
| `knowledge/御主资源库.md` | 御主建卡、主职业/子职业（人偶师、结界师等） |
| `knowledge/御主学科库.md` | 御主学科 |
| `knowledge/礼装资源书.md` | 礼装 |
| `knowledge/工房建筑书.md` | 工房/神殿组件（制裁机关、圣所基盘在这里） |
| `knowledge/规则书.md` | 职阶表、特效定义（爆发/封印/即死等）、魔力结算 |
| 用户 Downloads 的两份 PDF | RC1.14A 正式版 / beta2，文字层可提取（字间有空格，需去空格后再搜） |

**版本警告**：仓库 md 与 PDF、以及玩家手里的旧版可能不一致（例：支援咒术在扩充包只有 C 级，玩家口中的 B 级可能来自别的版本）。引用时标注出处；遇到不一致，写进 GM 裁决清单。

## 二、建卡硬规则（验算脚本会查，写卡时也别违反）

从者（预算 24RP）：
- 1RP = 10 属性；2RP = 1 额外宝具栏（基础 1 格，常规上限 3）
- 技能/宝具价格：A=5 B=4 C=3 D=2 E=1；加符 2RP；EX 技能 7RP / 宝具 9RP
- 栏位：3 职阶技能栏、3 保有技能栏（职阶技能基础 E 级白送，升级另按价格付）
- **面向限制**：技能六面向（天赋/技艺/祝福/兵器/荣冠/魔术）各至多 1 个；宝具十一面向各至多 1 个 → **召唤系宝具只能带一张**，想量产+巨像得靠御主那边
- 属性分配：必须 5 的倍数，单项分配上限 50（职阶基础属性另算）
- 剑阶特性：宝具栏上限 2；可放弃[骑乘]+10 点耐久基础属性换 +2RP
- 御主：12 初始 RP + 等级 RP（Lv40 = +12）；主职业+子职业决定可买技能池；3 保有技能栏（每 2RP 加 1 格）；另有 60 点免费属性（上限 50、5 的倍数）；工房用行动建造，不花 RP

## 三、搓卡流程

1. **问清需求**：核心宝具是什么？想要哪个流派？只搓本体、御主，还是「本体+御主+召唤物」整套系统？
2. **查原文**：用到的每张卡都去上面文件里找原文并记下文件+行号；找不到的问用户要 PDF 页码，**不许编效果**
3. **选底盘**：职阶基础面板差异很大（剑 100 点白送、术 30 点全在魔力），先定底盘再排账
4. **排 RP 账目表**：逐项列价
5. **跑验算脚本**（见下）
6. **四原型自检**（见下）
7. **出卡**：按输出格式

## 四、验算脚本（账目不过关不许出卡）

```
python "<skill_dir>\scripts\verify_build.py" --build 构筑.json
```

脚本查：RP 合计是否等于预算、属性是否 5 的倍数且不超上限、面向是否重复、栏位是否超限、宝具栏数 vs 职阶上限。
JSON 格式见 `scripts/example_build.json`（就是本对话搓的狮子环整套系统）。
**脚本报错必须改卡重跑，PASS 才许出卡。** 脚本只查账，效果联动是否成立仍是 AI/GM 的事。

## 五、四原型自检（每张卡必须作答，写在卡面「已知弱点」里）

真实对局总结出的四个生态位，互相克制：

| 原型 | 代表 | 强在 | 死法 |
|---|---|---|---|
| 封禁控制流 | 必胜黄金之剑+支援咒术+高速神言 | 战斗内滚雪球、-1级连砍封禁 | 长坂坡到场即死、月光+魂食 |
| 即死游击流 | 长坂坡一骑破阵 | 不接战斗直接摇人 | 幸运20减半、抗性、泡泡免疫 |
| 抗性堡垒流 | 病弱+虚荣的空中庭园 | 免疫判定+主场要塞 | 5%失败税、机动性差 |
| 经济雪球流 | 狮子环+圣所基盘 | 后期无限价值 | 前期战力真空 |

自检题（至少两题给出像样的答案，允许一题明说认输）：
1. **战斗层**：主力位靠什么赢？（等级差 / 属性压制 / 胜率链条）
2. **地图层**：被介入到场即死、被偷灵脉所有权怎么办？（幸运 ≥20 / 抗性堆叠 / 战斗续行 / 多线单位）
3. **经济层**：魔力从哪来、够养几个单位？（灵脉供魔 / 工房 / 魂食 / 神殿翻倍）
4. **防御层**：支援咒术式 -1 级连砍、即死、宝具封印各有什么答案？要不要对魔力？

## 六、经验教训库（真实死法提炼，搓卡时主动对照）

- **等级差是硬通货**：必胜黄金之剑每有一次宝具发动 +10 等级补正，等级差/2 = 常驻胜率
- **对魔力 A 专杀 C 级魔术连招**：降 5 级直接无效化——支援咒术流的天敌，也是召唤物选剑阶的理由
- **制裁机关 + 咒术可对 A 级宝具连砍 5 次封禁**（主场限定；工房御主用行动盖，不花 RP）
- **狮子环「任意体」无数量上限**（三份版本文本一致，其他召唤卡会写「至多X体」），实际数量被魔力经济卡死；每职阶技能限一次 → 标配：狂（打手）/术（能建神殿）/杀（偷家）/剑（对魔力门神）/弓（侦查）
- **虚荣的空中庭园在当前版是大灵脉级要塞**：魔力量 60 + 免疫外来技能宝具与干涉 + 主力位 +20 等级/+20 属性/+20% 抗性 + A 级召龙种人偶海
- **魂食是移动经济**，不点灯不建家的对手会用它；人流量 0 的灵脉（如庭园）天然断魂食
- **长坂坡式即死发生在"到达灵脉后"**，战斗开始前——战斗层构筑全部失效，只有幸运/抗性/战斗续行/令咒救得住

## 七、输出格式

1. **卡面总览**：职阶、底盘、最终三围（基础+分配分开列）
2. **RP 账目表**：逐项价格 + 合计 + 「脚本 PASS」标记
3. **原文引用**：每张卡的效果附文件+行号（或 PDF 页码）
4. **战术**：前期 / 中期 / 后期各一段
5. **已知弱点**：诚实写，含对四原型自检的答案
6. **GM 裁决清单**：原文含糊处全部列出（例：「任意体」「魔力量算不算池」「爆发后能否再触发高速神言」「庭园算不算降临灵脉」）
