# 测试卡说明

这批 `.st` 卡只用于测试导入、角色选择、战斗表属性合计、魔力回写和复盘流程，不追求还原原作强度。

## 资源预算

- 从者全部使用最高初始等级 `Lv70`，对应 `160` 可分配属性。
- 御主全部使用最高初始等级 `Lv40`，资源点为 `12 PRP + 12 LRP = 24RP`。
- 御主属性使用固定 `60` 可分配属性。
- 从者等级不是额外购买属性；御主等级也不是额外购买属性。
- 技能和宝具按 `A=5 / B=4 / C=3 / D=2 / E=1` 核算。
- 初始槽位不额外收费：从者默认 3 职阶技能栏、3 保有技能栏、1 宝具栏；御主默认 1 工房栏、3 保有技能栏、1 礼装栏。
- 为了避免测试时隐藏常驻补正干扰，所有从者 `补正*` 字段都先写成 0。

## 用法

在后端运行时执行：

```bash
cd backend-node
node import-test-cards.js
```

导入脚本会创建或复用 `测试杯` 战役，并导入 `test/从者` 与 `test/御主` 下的 14 张卡。
