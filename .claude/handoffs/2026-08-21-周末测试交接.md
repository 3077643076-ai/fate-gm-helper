## 周末推荐测试顺序
1. 运行 `npm install` 或 `npm run install:all`，确认依赖完整。
2. 运行 `npm test` 和 `npm run build`。
3. 双击 `start-local.bat`，打开 `http://localhost:8100`。
4. 导入或上传真实角色卡，至少准备蓝方和黄方各 1 张从者卡。
5. 在战斗表跑：编队、战术、技能队列、工序确认、结算确认。
6. 检查角色状态：魔力是否回写，状态效果/备注是否可读。
7. 检查复盘历史：是否保存本场摘要。
8. 运行 `npm run backup`，保存测试后的 SQLite 备份。

## 已知风险
- 后端战斗表目前主要是保存 JSON，不是完整规则引擎；胜率和技能套用主要在前端计算。
- 结算确认由前端串行调用多个接口，中途失败可能出现半完成状态。
- 状态效果默认写给技能持有者；敌方目标、持续时间、层数叠加仍需 GM 手动裁决。
- `config.json`、`settings.json`、`my-koishi-bot/koishi.yml`、旧 `backend` 配置里曾出现密钥或密码；推送前已改为忽略/示例配置，但建议立刻重置已暴露的 token。
