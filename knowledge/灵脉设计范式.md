# 灵脉设计范式与知识库

> 本文档汇总了耶路撒冷系列、北之岛群岛、天衡武馆系列、小镇系列、巨型坑洞系列等灵脉设计的核心规则与设计范式，用于指导后续灵脉的创建与规则书写。

---

## 一、灵脉基础结构

每个灵脉由以下维度构成：

| 维度 | 含义 | 常见取值 |
|------|------|----------|
| **魔力量** | 决定供魔能力与技能消耗参考 | 10~60，通常为 10 的倍数 |
| **战场宽度** | 决定战斗编队空间 | 3~7 |
| **人流量** | 动态资源，驱动轮次结算与条件触发 | 0~6，通常为整数 |
| **灵魂力**（可选） | 部分灵脉的第四维度，用于更复杂机制 | 0~6 |

**原则**：三围尽量用简洁整数，便于 GM 快速心算。

## 二、灵脉效果分类

### 2.1 被动常驻效果

无需宣言，满足条件即自动生效。

```
示例：持有[魔性]的单位在此灵脉发生的战斗中始终获得[-50%]胜率惩罚。
示例：每轮次结束时，位于此灵脉的全部单位获得[+20]魔力补给。
```

### 2.2 宣言触发效果

需要消耗行动阶段、魔力或其他资源来发动。

```
示例：允许御主单位消耗行动阶段进行[托孤]，指定自阵营一名单位令其获得[遗志]。
示例：宣言消耗[20]魔力，玩家指定对方战斗位上任一单位，给予其[-15%]胜率惩罚。
```

### 2.3 轮次结算效果

每轮结束时自动触发，无需额外操作。

```
示例：每轮次结束时，此灵脉人流量[+1]（至多为[5]）。
示例：轮次结束时，若当前灵脉存在在本轮次进行过[魂食]的单位，则本轮次当前灵脉的所有单位无法获得该灵脉供魔。
```

## 三、条件触发设计模式

好的灵脉效果几乎都是**条件式**的，常见条件维度：

| 条件类型 | 说明 | 示例 |
|----------|------|------|
| **背景条件** | 从者背景典出特定作品 | 典出【基督教】/【伊斯兰教】 |
| **属性条件** | 持有特定属性或特性 | 持有【神性】【魔性】【抗性】 |
| **位置条件** | 单位在灵脉上的位置 | 主力位/辅助位/战斗位上 |
| **状态条件** | 持有特定状态及层数 | 持有[骄]1~3层 |
| **事件条件** | 发生特定游戏事件 | 发生战斗/进行魂食/人流减少 |
| **数值条件** | 等级差、魔力池、灵魂力阈值 | 等级＜60、灵魂力≥5 |
| **交叉条件** | 多个条件同时满足 | "当前灵脉存在单位且其曾在此灵脉获得战斗胜利" |
| **来源条件** | 指定灵脉来源的单位 | 来自【旧城城墙】的单位 |

## 四、数值设计节奏

| 效果类型 | 推荐范围 | 极端值 |
|----------|----------|--------|
| 胜率补正 | ±10% ~ ±50% | 少量 ±60%~70% |
| 等级补正 | +5 ~ +20 | — |
| 属性补正 | +5 ~ +15 per 属性 | — |
| 魔力补给 | +10 ~ +50 per 回合 | — |
| 惩罚/限制 | -10% ~ -25% | 极端 -50% |
| 行动消耗 | 10~30 魔力 | — |

**黄金法则**：补正类效果优先用**层数叠加**（如 [骄1]~[骄3]），而非直接写死高数值，这样 GM 可以按层数直觉计算。

### 层数系统参考

| 状态名 | 层数范围 | 每层效果 | 触发方式 |
|--------|----------|----------|----------|
| [骄] | 1~3 | +10% 胜率 | 战斗胜利获得 |
| [哀] | 1~3 | +15% 胜率 | 战斗失败获得 |
| [乐不思蜀] | 1~3 | +10% 胜率 | 奏乐判定成功 |
| [残存的光] | 1~6 | +10% 胜率 | 完整轮次持有 |
| [畅销] | 1~14 | 满层全单位补魔 | 首次获魔力补给累计 |
| [纷争] | 累加 | +5% 属性补正 per 层 | 战斗进入主要工序 |
| [恩义] | 1~3 | 消耗1可使撤退免FP | 放行获得 |
| [极光] | 任意 | +20 魔力 per 层 | 夜回合宣言获得 |

## 五、灵脉间交互模式

```
- 跨灵脉条件：A 灵脉效果依赖 B 灵脉的状态（如哭墙依赖"发生过人流减少"）
- 人流传播：一个灵脉的人流变化影响其他灵脉（如后巷、小镇大厅）
- 锁定/限制：某些灵脉禁止离开、禁止魂食、禁止特定行动
- 空间转移：战斗被移到特定战场宽度（如 K 公司移到宽度 6 游荡）
```

## 六、特殊行动系统

每个灵脉可设计专属行动（需消耗行动阶段）：

| 行动名 | 效果 | 示例灵脉 |
|--------|------|----------|
| [习武] | 判定成功获得属性补正 | 天衡武馆 |
| [奏乐] | 判定成功获得魔力补给+状态层 | 洛阳 |
| [托孤] | 指定单位获得[遗志] | 白帝城 |
| [自刎归天] | 退场但不给对方击杀奖励 | 殉义坡 |
| [逛街] | 判定获得礼装 | 商业街 |
| [医疗] | 移除属性惩罚 | 医院 |
| [冥想] | 自选一项增益 | 深山 |
| [修复] | 激活工房组件 | 废弃的魔术工房 |
| [探索] | 解锁未知灵脉信息 | 寂静的小镇、幽静的庄园 |
| [介入]/[干涉] | 跨灵脉行动 | 各灵脉通用 |
| [魂食] | 消耗单位获取魔力 | 各灵脉通用 |
| [休整] | 恢复类行动 | 各灵脉通用 |

## 七、退场与所有权失去规则

```
- 失去灵脉时清除效果（常驻补正消失、额外技能失去）
- 部分效果在离开灵脉后失去（如远视之魔眼、回路补正）
- 战斗结束/轮次结束清除临时补正（如长坂坡全属性+15）
- 额外技能视为临时获得，离开灵脉时失去
```

## 八、强度与获取难度匹配

灵脉效果的强度必须与其获取代价成正比。评估维度：

```
获取代价 = 持有回合数 + 宣言行动消耗 + 魔力消耗 + 战略风险
```

| 代价等级 | 持有条件 | 效果参考 |
|----------|----------|----------|
| 低 | 无持有要求/1回合 | 单体-10%~-15%胜率，补正+5%~+10% |
| 中 | 2~3回合 | 单体-15%~-20%胜率，补正+10%~+20% |
| 高 | 5回合+行动 | 单体-15%~-20%×多阶段（累计-60%），补正+20%~+30% |

**原则**：
- 高代价灵脉的单次效果可以温和，但累计或叠加后应达到高阶水平
- 低代价灵脉的单次效果要克制，避免喧宾夺主
- 纯被动灵脉（无宣言成本）效果应弱于有宣言成本的灵脉
- 允许"不使用就无用"的设计（如空城被动收益），增加策略深度

## 九、避坑清单

| 反模式 | 正确做法 |
|--------|----------|
| 效果过多（>3 条核心） | 精简到 2~3 条，v2 已验证 |
| 数值直接写死高值 | 用层数叠加，GM 可心算 |
| 条件过于复杂（>3 个 AND） | 拆成多个简单条件或层数 |
| 灵脉间强依赖导致连锁 | 用中间状态（如[骚乱]）解耦 |
| 离开灵脉后效果还残留 | 明确标注"离开时失去" |
| 灵魂力/魔量无下限保护 | 加"最少为1"或"不会变为0" |
| 工房组件无获取限制 | 明确修复次数、稳态消耗等门槛 |
| 强度与代价不匹配 | 按"八、强度与获取难度匹配"评估
